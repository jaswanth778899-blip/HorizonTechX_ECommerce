# HorizonTechX E-Commerce Website

## 📌 Project Overview

A modern and responsive e-commerce website developed as part of the Horizon TechX Full Stack Development Internship.

The project provides an online shopping experience with a clean user interface for browsing and purchasing products.

## 🚀 Features

- 🛍️ Product listing
- 📦 Product details
- 🛒 Shopping cart
- 🔐 User login and registration
- 💳 Order placement
- 📋 Order management
- 📱 Responsive design
- 🔎 Product search and browsing

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
